1 Pengenalan Aplikasi

PGRI Sine Store adalah aplikasi pemesanan kaos seragam PGRI Cabang Kecamatan Sine dalam rangka menyambut HUT PGRI ke-81 tahun 2026.

Akses Aplikasi:
https://mahalawu.github.io/81pgri/

Fitur utama:

  • 🛒 Pemesanan kaos seragam secara online
  • 🎨 Lihat katalog produk dengan rotasi gambar otomatis
  • 📦 Pantau status pesanan real-time
  • 🗳️ Ikut survei warna seragam favorit
  • 📊 Rekapitulasi pesanan transparan
Info Token Keamanan:
Setiap pemesanan memerlukan Token Keamanan yang dapat diminta kepada pengurus PGRI Cabang Sine. Token ini berfungsi untuk mencegah pemesanan palsu.

2 Alur Pemesanan

Ikuti langkah-langkah berikut untuk memesan kaos seragam PGRI.

1
Buka Aplikasi

Akses link mahalawu.github.io/81pgri/ melalui browser HP atau komputer.

Aplikasi bisa diakses tanpa install, langsung dari browser.
2
Pilih Produk Kaos

Lihat katalog produk. Gambar produk akan berganti otomatis setiap 5 detik — arahkan kursor untuk menghentikan rotasi dan melihat detail.

3
Atur Ukuran & Jumlah

Pilih ukuran (S, M, L, XL, XXL, XXXL), lalu klik tombol + Keranjang. Ulangi untuk item lain jika perlu.

Bisa pesan beberapa jenis kaos dengan ukuran berbeda sekaligus.
4
Review Keranjang

Klik ikon Keranjang di navbar. Periksa rincian item, ubah jumlah jika perlu, dan pastikan total sudah benar.

5
Isi Data Pemesan

Klik Lanjut Checkout, lalu isi:

  • Nama Pemesan / Penanggung Jawab
  • Asal Ranting / Sekolah
  • Nomor WhatsApp aktif
  • Jenis pesanan (Mandiri / Kolektif)
  • Metode pembayaran (Transfer / Tunai)
Nomor WA harus aktif — digunakan untuk konfirmasi pesanan.
6
Validasi Token & Kirim Pesanan

Masukkan Token Keamanan dari pengurus, lalu klik Kirim Pesanan.

Token berbeda untuk setiap event — minta ke pengurus cabang.
7
Simpan ID Pesanan

Setelah berhasil, aplikasi akan menampilkan ID Pesanan (contoh: PGRISINE-81101).

PENTING: Catat / screenshot ID ini untuk cek status pesanan nanti.
8
Konfirmasi Pembayaran via WhatsApp

Setelah pesanan tersimpan, aplikasi akan membuka WhatsApp otomatis ke nomor admin. Kirim bukti transfer (jika metode Transfer) ke admin.

3 Cara Cek Status Pesanan

1
Buka Menu "Cek Pesanan"

Klik tombol Cek Pesanan di navbar atas halaman toko.

2
Masukkan ID + Nomor WA

Isi ID Pesanan (contoh: PGRISINE-81101) dan Nomor WhatsApp yang digunakan saat memesan.

3
Lihat Hasil

Sistem akan menampilkan:

  • Status pembayaran (Lunas / Belum Lunas)
  • Status konveksi (Draft / Diproses / Selesai)
  • Rincian item yang dipesan
  • Total tagihan
Lupa ID Pesanan?
Hubungi admin via WhatsApp dengan menyebutkan nama lengkap dan ranting asal.

4 Panduan Admin & Operator Konveksi

Halaman ini hanya untuk pengurus PGRI yang memiliki akses khusus.

Cara Login
  1. Klik tombol Admin di navbar toko.
  2. Masukkan PIN / Token yang diberikan pengurus.
  3. Klik Masuk Dashboard.
Role & Hak Akses
ADMIN
  • Akses Kelola Pesanan
  • Update status bayar (Lunas / Belum)
  • Ubah status konveksi (bebas)
  • Hapus pesanan
  • Akses Rekap Konveksi
  • Cetak / Save PDF rekap
OPERATOR KONVEKSI
  • Hanya akses Rekap Konveksi
  • Lihat detail pesanan produksi
  • Update status konveksi hanya maju:
    Draft → Diproses → Selesai
  • Tidak bisa mundurkan status
  • Cetak / Save PDF rekap
Update Status Konveksi
  1. Buka menu Rekap Konveksi.
  2. Cari pesanan yang ingin di-update (bisa pakai filter / search).
  3. Ubah dropdown di kolom Status.
  4. Perubahan tersimpan otomatis.
Cetak Rekap:
Klik tombol Cetak / Save PDF di kanan atas tabel Rekap Konveksi. Jendela print akan terbuka — pilih "Save as PDF" untuk menyimpan.

5 Pertanyaan Umum (FAQ)

Saya lupa ID Pesanan, bagaimana?

Hubungi admin via WhatsApp dengan menyebutkan nama lengkap, ranting/sekolah, dan tanggal pemesanan. Admin akan mencarikan ID-nya.

Bagaimana cara mengubah pesanan saya?

Pesanan hanya bisa diubah selama status konveksi masih Draft (belum masuk proses produksi). Hubungi admin secepat mungkin jika ada perubahan.

Token keamanan apa itu? Di mana saya mendapatkannya?

Token keamanan adalah kode unik yang diberikan oleh pengurus PGRI Cabang Sine untuk memvalidasi pesanan. Token dapat diminta melalui pengurus ranting atau admin WhatsApp.

Kapan pesanan saya bisa diambil?

Setelah status konveksi berubah menjadi Selesai. Anda bisa cek statusnya lewat menu "Cek Pesanan" di aplikasi.

Apakah bisa pesan kolektif untuk satu sekolah?

Bisa. Saat checkout, pilih jenis pesanan Kolektif dan isi nama ranting/sekolah. Untuk jumlah besar, disarankan koordinasi dulu dengan admin.

Bagaimana jika saya tidak sengaja memesan dua kali?

Aplikasi akan menampilkan peringatan jika terdeteksi pesanan ganda untuk ranting yang sama. Namun jika tetap terjadi, hubungi admin untuk penghapusan salah satu pesanan.

Metode pembayaran apa saja yang tersedia?

Dua metode: Transfer Bank (via BPD Jatim) atau Tunai / Offline (setor langsung ke Sdr. Nur Cahyo Widodo di Korwil Sine).

Butuh Bantuan?

Jika ada pertanyaan atau kendala, hubungi admin kami melalui WhatsApp.
Respon cepat di jam kerja: 07.00 – 21.00 WIB
